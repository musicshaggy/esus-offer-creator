# Lokale deutsche PLZ-/Ortsdaten

Quelle: GeoNames Postal Code Dataset, https://www.geonames.org/
Download: https://download.geonames.org/export/zip/DE.zip
Abgerufen am 11.10.2026. Lizenz laut beiliegendem Readme: Creative Commons
Attribution 4.0. https://creativecommons.org/licenses/by/4.0/

`de-postcodes.json` enthält aus DE.txt nur PLZ und Orts-/Institutionsnamen.
Die Daten sind nicht amtlich und können unvollständig oder fehlerhaft sein.
Sie dienen zur Vorbelegung eines bearbeitbaren Länder-Vorschlags. Ein Treffer
ist keine Prüfung der postalischen Zustellbarkeit. Ausländische Adressen werden
nur bei ausdrücklich enthaltenem Land/Länderpräfix zugeordnet. Keine automatische
Aktualisierung und keine externen Adressabfragen während der Rechnungsverarbeitung.
